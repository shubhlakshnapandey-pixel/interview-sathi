This is an AI-powered mock interview platform designed to help Hindi, Awadhi, and Bhojpuri speaking students improve their professional English communication for job interviews.
Project Structure ->
interview-sathi/
├─ backend/                       # Server APIs
│   ├─ app.py or server.js        # Entry point
│   ├─ routes/                    # API endpoints
│   ├─ controllers/               # Logic handling
│   ├─ services/                  # AI + DB services
│   └─ models/                    # DB models
│
├─ frontend/                      # React app
│   ├─ public/                    # Static assets
│   ├─ src/
│   │   ├─ components/            # UI components
│   │   ├─ pages/                 # Page views
│   │   ├─ utils/                 # Helpers
│   │   └─ App.js                 # Root component
│
├─ db/                           # Database setup (schemas/migrations)
│
├─ .env                         # Config vars (API keys)
├─ package.json                 # JavaScript deps
├─ requirements.txt             # Python deps (if backend uses Python)
└─ README.md                   # Project info
